Lecture 2 / Assigning probabilities

What makes a probability model valid?

Events tell us what can happen. Probability assigns a number to how likely each event is.

A probability function takes an event A and returns P(A). It must obey three basic requirements:

  1. Nonnegativity: \(P(A)\ge0\).
  2. Normalization: \(P(\Omega)=1\). Some outcome in the sample space must occur.
  3. Additivity: probabilities add for disjoint alternatives. If \(A_i\cap A_j=\varnothing\) whenever \(i\ne j\), then:
\[P\!\left(\bigcup_{i=1}^{n}A_i\right)=\sum_{i=1}^{n}P(A_i).\]

The formal axiom also holds for a countably infinite sequence of pairwise disjoint events. For the finite examples in these photos, the finite version is enough. Together, the axioms imply \(0\le P(A)\le1\) and \(P(\varnothing)=0\).

“Pairwise disjoint” matters. Every pair must have an empty intersection. Having only \(A\cap B\cap C=\varnothing\) does not justify adding P(A), P(B), and P(C): there may still be pairwise overlaps.

  1. Which weights form a valid model for three exhaustive outcomes?

    Answer: 0.2, 0.3, 0.5 Only 0.2, 0.3, 0.5 meets both requirements. The second sums to 1.1; the third includes a negative weight.

  2. Three mutually exclusive events cover Ω. Their probabilities are 0.12, 0.53, and p. Find p.

    Answer: 0.35 p = 1 − 0.12 − 0.53 = 0.35.

  3. Which conclusions always follow from the axioms?

    Answer: P(Ω) = 1; P(∅) = 0; A ⊆ B implies P(A) ≤ P(B) Normalization, the empty-event rule, and monotonicity hold. In continuous models, a nonempty singleton can have probability zero.

From individual outcomes to an event

In a finite sample space, assign a weight \(p_i\ge0\) to each outcome \(\omega_i\), with \(\sum_i p_i=1\). Then add the weights of the outcomes that belong to A:

\[P(A)=\sum_{\omega_i\in A}p_i.\]

If all N outcomes are equally likely, each has weight 1/N, giving \(P(A)=|A|/N\). A fair die therefore has \(P(\{i\})=1/6\) for each face, and \(P(\{2,4,6\})=3/6=1/2\). “Random” on its own does not guarantee equal likelihood.

Add outcome weights

0/3 solved

  1. Ω = {a, b, c, d} has probabilities 0.1, 0.2, 0.3, 0.4. Find P({b, d}).

    Answer: 0.6 0.2 + 0.4 = 0.6. The event contains two outcomes, but its probability is not 2/4 because the outcomes are unequal.

  2. Using the same four weights, find P({a, c}ᶜ).

    Answer: 0.6 P({a, c}) = 0.1 + 0.3 = 0.4, so its complement has probability 0.6.

  3. An event contains half the outcomes in a finite sample space. Must it have probability 1/2?

    Answer: No Only equal outcome probabilities guarantee the count ratio. Otherwise half the outcomes can carry more or less than half the total weight.

Three rules you will use repeatedly

RuleFormulaReason
Complement\(P(A^c)=1-P(A)\)A and not-A are disjoint and cover Ω.
Union\(P(A\cup B)=P(A)+P(B)-P(A\cap B)\)Remove the overlap counted twice.
Containment\(A\subseteq B\Rightarrow P(A)\le P(B)\)B contains everything in A, possibly more.

For three events, inclusion–exclusion adds the individual probabilities, subtracts the three pairwise overlaps, and adds back the triple overlap:

\[P(A\cup B\cup C)=P(A)+P(B)+P(C)\]\[{}-P(A\cap B)-P(A\cap C)-P(B\cap C)+P(A\cap B\cap C).\]

Combine probabilities carefully

0/3 solved

  1. P(A) = 0.7 and P(B) = 0.6. What is the smallest possible P(A ∩ B)?

    Answer: 0.3 P(A ∩ B) ≥ P(A) + P(B) − 1 = 0.3. This lower bound is attainable.

  2. P(A), P(B), P(C) are 0.3, 0.4, 0.2. Pairwise overlaps are 0.1, 0.05, 0.08, and the triple overlap is 0.02. Find the union probability.

    Answer: 0.69 0.3 + 0.4 + 0.2 − 0.1 − 0.05 − 0.08 + 0.02 = 0.69.

  3. If A ⊆ B and P(A) = 0.4, which value of P(B) is impossible?

    Answer: 0.3 P(B) must be at least 0.4, so 0.3 is impossible.

Board example / Photos 2 and 5

Two interviews: “at least one” and “neither”

Let A mean success in the first interview and B success in the second. The board gives \(P(A)=0.8\), \(P(B)=0.6\), and \(P(A\cap B)=0.5\).

At least one success:

\[P(A\cup B)=0.8+0.6-0.5=0.9.\]

Both interviews unsuccessful: this is the complement of at least one success.

\[P(A^c\cap B^c)=1-P(A\cup B)=0.1.\]

To check the whole model, divide it into four disjoint outcomes:

OutcomeProbability
Both successful0.5
First only0.8 − 0.5 = 0.3
Second only0.6 − 0.5 = 0.1
Neither0.1

All entries are nonnegative and sum to 1. Exactly one success has probability 0.3 + 0.1 = 0.4, which differs from “at least one.”

Do not replace the given overlap 0.5 with \(0.8\times0.6\). Multiplying marginal probabilities would require independence, which is not given and does not hold for these values.

At least one, exactly one, neither

0/3 solved

  1. Two tests succeed with P(A) = 0.7, P(B) = 0.5, and P(A ∩ B) = 0.4. Find the probability of at least one success.

    Answer: 0.8 0.7 + 0.5 − 0.4 = 0.8.

  2. For those same two tests, find the probability of exactly one success.

    Answer: 0.4 A only is 0.7 − 0.4 = 0.3; B only is 0.5 − 0.4 = 0.1. Total: 0.4.

  3. For those same two tests, find the probability of neither success.

    Answer: 0.2 1 − 0.8 = 0.2. This is not the probability of exactly one success.

Board example / Photos 1 and 6

The mechanic: add outcomes or subtract a tail

Let X be the number of cars serviced in a day. The probability table visible on the board is:

x012345678
P(X = x).03.08.12.14.17.16.14.09.07

These nine values sum to 1. Outcomes such as “X = 7” and “X = 8” cannot occur together, so their probabilities add.

\[P(X<7)=1-P(X\ge7)=1-0.09-0.07=0.84.\]

You can also add the probabilities for 0 through 6. The complement is shorter because only two values lie outside the event.

Watch the boundary: “fewer than 7” means 0–6, not 0–7. “At most 7” includes 7 and gives 0.93. “At least 7” includes 7 and gives 0.16.

0/3 solved

  1. X takes values 0, 1, 2, 3 with probabilities 0.1, 0.2, 0.4, 0.3. Find P(X < 2).

    Answer: 0.3 P(X < 2) = 0.1 + 0.2 = 0.3.

    Answer: 0.7 0.4 + 0.3 = 0.7. It is the complement of X < 2, not X ≤ 2.
