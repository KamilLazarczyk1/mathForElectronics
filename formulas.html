08 / Quick revision

The formula desk

Relative frequency
\(f_N(A)=N_A/N\)

Observed count of A divided by the number of trials; an estimate of P(A).

Equally likely finite outcomes
\(P(A)=|A|/|\Omega|\)

Only when all outcomes in the finite sample space have the same probability.

Complement / not
\(A^c=\Omega\setminus A,\quad P(A^c)=1-P(A)\)
Union / inclusive or
\(P(A\cup B)=P(A)+P(B)-P(A\cap B)\)
Mutually exclusive / disjoint
\(A\cap B=\varnothing\Rightarrow P(A\cup B)=P(A)+P(B)\)
De Morgan / neither / not both
\((A\cup B)^c=A^c\cap B^c,\quad(A\cap B)^c=A^c\cup B^c\)
Factorial / arrange all distinct objects
\(n!=n(n-1)\cdots1,\quad0!=1\)
Ordered choices / repetition allowed
\(n^k\)

k positions, n choices at each position.

Permutation / variation / ordered, no repetition
\(P(n,k)=n!/(n-k)!\)

Choose k distinct objects in order from n; 0 ≤ k ≤ n.

Combination / Newton’s symbol / unordered, no repetition
\(\binom nk=n!/[k!(n-k)!]\)

Choose a k-element subset of n distinct objects; 0 ≤ k ≤ n.

Permutation of a multiset / identical objects
\(n!/(n_1!\cdots n_r!)\)

Fixed multiplicities n₁ + ⋯ + nᵣ = n.

Binomial theorem / Newton expansion
\((a+b)^n=\sum_{k=0}^n\binom nk a^{n-k}b^k\)

n is a nonnegative integer.

Probability axioms / pairwise disjoint addition
\(P(\Omega)=1,\quad P(A)\ge0,\quad P(\bigcup_i A_i)=\sum_i P(A_i)\)

The addition equality requires pairwise disjoint events; it applies to finite or countable unions.

Conditional probability / given
\(P(A\mid B)=\frac{P(A\cap B)}{P(B)}\)

Require P(B) > 0. The event after the bar is the denominator.

Multiplication / intersection
\(P(A\cap B)=P(B)P(A\mid B)\)

General product rule; it does not require independence. The displayed conditional requires P(B) > 0.

Conditional complement
\(P(A^c\mid B)=1-P(A\mid B)\)

Keep the condition B unchanged; require P(B) > 0.

Three-event inclusion–exclusion
\(P(A\cup B\cup C)=P(A)+P(B)+P(C)-P(A\cap B)-P(A\cap C)-P(B\cap C)+P(A\cap B\cap C)\)

Subtract pairwise overlaps and restore the triple overlap.

Poker / exactly one pair
\(N=13\binom42\binom{12}{3}4^3\)

Five-card hands from a 52-card deck. Probability = N / C(52,5).

Poker / at least one repeated rank
\(N=\binom{52}{5}-\binom{13}{5}4^5\)

Includes pairs, triples, and four of a kind.
